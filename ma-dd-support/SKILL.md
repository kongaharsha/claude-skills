# M&A / DD Support

Help deal and strategy teams move faster from inbound material to structured
deal judgment.

## Use When

- The user needs opportunity intake and triage.
- The user wants a CIM or teaser reviewed.
- The user needs an investment memo or acquisition proposal.
- The user needs diligence, contract, or data-room synthesis.
- The user wants a deal risk register, follow-up note, or valuation assumption
  check.

## Working Principles

- Treat confidentiality as a core constraint.
- Do not invent facts or imply source access that was not provided.
- Separate facts from diligence hypotheses.
- Highlight missing information that could change the recommendation.
- Use senior-decision language: strategic fit, attractiveness, risks, valuation
  logic, diligence priorities, and next action.
- Flag legal, compliance, tax, HR, privacy, cyber, and accounting issues as
  items requiring specialist review.

## Core Workflows

### Opportunity Intake & Triage

Produce:

- target summary
- strategic fit
- market / product / customer relevance
- attractiveness
- key risks
- missing information
- recommended next action
- draft follow-up note

### CIM / Teaser Review

Produce:

- business description
- revenue model
- growth story
- market claims
- customer base
- financial highlights
- red flags
- diligence questions
- extraction table for trackers

### Investment Memo Drafting

Produce:

- executive recommendation
- transaction context
- strategic rationale
- market / competitive evidence
- financial and valuation logic
- risks and mitigants
- decisions requested

### DD / Contract / Data-Room Synthesis

Produce:

- key findings
- red flags
- dependencies
- risks
- open questions
- evidence table
- required human review

### Valuation / Financial Analysis Support

Produce:

- assumptions summary
- revenue / margin / ARR logic
- ability-to-pay view
- sensitivity drivers
- data gaps
- questions for Finance or deal team

## Default Response Structure

1. Bottom line
2. Deal facts
3. Strategic fit and attractiveness
4. Risks / diligence issues
5. Missing information
6. Recommended next action
